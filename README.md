# 🚴‍♂️ Bike Sales and Demographic Analysis | Excel Dashboard

This project is an interactive Excel dashboard developed to analyze **bike sales trends** using demographic data such as **income**, **age**, **commute preferences**, **gender**, **location**, and **education level**. The dashboard provides clear, visual insights into customer behavior and preferences using **Pivot Tables**, **Pivot Charts**, and **Slicers**.

## 📊 Features

- **Interactive Dashboard:** Clean and user-friendly layout for exploring data with slicers and pivot charts.
- **Income & Age Analysis:** Understand how income and age vary across gender, education, and location.
- **Commute Preferences:** Identify patterns in how customers commute and their relation to bike purchases.
- **Dynamic Filters:** Slicers allow users to filter data by **Gender**, **Location**, and **Education** for customized insights.
- **Visualized Data:** Graphs and charts make it easier to spot trends in customer behavior and purchasing decisions.

## 🧠 Insights Derived

- Which income groups are more likely to purchase bikes.
- Age demographics with the highest bike purchase rate.
- How gender, location, and education influence commute and buying behavior.
- Regional and educational differences in bike commuting trends.
